# jobhq

A simple "Notion for Jobs" AI-powered Chrome extension I built long ago for myself while job hunting, then cleaned up and launched for fun. Live at [jobhq.co](https://jobhq.co).

I was applying across a lot of sites and kept losing track of postings, deadlines and incomplete applications I started but never finished. LinkedIn's saved jobs only works on LinkedIn, so I built something that works everywhere and remembers the annoying parts for me.

## What it does

- Save any posting in one click, from any site.
- Track the progress of each application in the app, including application questions, saved answers, deadlines, interview-dates
- Automatically scheduled app and email reminders for application and interview deadlines
- Watches saved postings for tracking changes.
- Drafts cover letters and application answers with AI, and autofills forms from what you've already written.

Chrome extension (Manifest V3) with a small web app behind it at [jobhq.co](https://jobhq.co).
