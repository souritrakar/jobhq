# jobhq

A little AI-powered Chrome extension I built for myself while job hunting, then cleaned up and launched for fun. Live at [jobhq.co](https://jobhq.co).

I was applying across a lot of sites and kept losing track of postings. LinkedIn's saved jobs only works on LinkedIn, so I built something that works everywhere and remembers the annoying parts for me.

## What it does

- Save any posting in one click, from any site.
- Track where each application stands.
- Reminders so deadlines don't slip.
- Watches saved postings for changes.
- Drafts cover letters and application answers with AI, and autofills forms from what you've already written.

Chrome extension (Manifest V3) with a small web app behind it at [jobhq.co](https://jobhq.co).
